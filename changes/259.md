## Added

- Added server-only Buffer configuration with `bufferConfigured()`, canonical `BUFFER_API_KEY` handling, and optional `BUFFER_ORGANIZATION_ID` when an account has more than one organization.
- Added a read-only Buffer GraphQL adapter that lists organizations, channels, and paginated posts, refuses HTTP 200 GraphQL errors and typed failures, and maps only explicit TikTok and YouTube services onto publishing accounts.
- Buffer channel metadata refreshes as one complete generation on publish preview, publish-target save, or an explicit refresh, records one redacted integration event, and leaves the prior generation untouched when a read fails.

## Breaking changes

None.
