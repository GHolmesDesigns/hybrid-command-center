## Added

- Command AI drawer synchronization for client, project, and task threads alongside freeform conversations, including canonical thread resolution, secondary thread badges, and a scope-change prompt when page context differs from the selected thread.
- Scoped conversation resolution and promote-to-canonical API routes backed by an additive `is_canonical` column and partial unique index.

## Changed

- The conversation selection bridge now treats active scoped threads as drawer-eligible instead of freeform-only.
- Conversations and Command AI help copy now describe canonical versus secondary scoped threads and the scope-change prompt.

## Breaking changes

None.
