## Added

- Settings includes a **Default views** card for Clients visibility, Projects visibility and sort,
  Calendar view, and Signal view. A configured default applies when the address omits that choice;
  an explicit URL still wins. Reset restores the shipped defaults.

## Changed

- Calendar and Signal documentation now describe the shipped default as the current month, matching
  the code. Invalid or stale stored view defaults fail safely to those shipped values.

## Breaking changes

None.
