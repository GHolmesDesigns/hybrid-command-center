## Changed

- After a clearly answered Confirm and submit (or Confirm publish now), delivery results appear in
  the same panel without pressing **Refresh delivery** — the existing bounded reconcile path runs
  once against the stored provider ids.
- Ambiguous, timed-out, rate-limited, or otherwise unclear submits do not auto-refresh, do not
  create a second post, and do not invent certainty; inspect-before-retry guidance stays on screen.
- **Refresh delivery** remains available later. Planning status is never written by this path.
  Post Bridge and Buffer rate-limit accounting stay isolated.

## Breaking changes

None.
