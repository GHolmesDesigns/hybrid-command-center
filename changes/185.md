### Changed

- Each posting channel now has a look of its own. Blog, Instagram, X, Bluesky, LinkedIn,
  Facebook, TikTok, and YouTube each get their own chip fill, outline, and text colour, so a
  planner cell or the channel list in the editor separates at a glance instead of reading as a
  column of identical grey tags. Every chip still carries its initial, and its full name is still
  read aloud, so the eight stay apart in greyscale and with colours turned off — the colour is a
  second cue and never the only one. Every combination clears WCAG AA contrast for small text,
  measured with the same rules the sidebar branding is held to. A value the app does not
  recognise as a channel is drawn in a neutral treatment that shows the value itself rather than
  disappearing.
- No logo, icon, or externally hosted image was added for any channel; these are colours only.

### Breaking changes

None.
