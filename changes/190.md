## Added

- Signal post editors now offer reusable local channel presets for all channels, visual social,
  professional publishing, and short-form video. Applying a preset fills the selection as a
  starting point, and every channel remains editable before saving.
- Presets keep stable channel identifiers. If a saved identifier is no longer available, Signal
  excludes it by name instead of silently choosing another channel.

## Breaking changes

None.
