## Added

- Signal has one Add Post flow shared by day cells, the unscheduled queue, and the top navigation.
  Every entry point opens the same editor: a day-cell plus prefills that local `YYYY-MM-DD` date, and
  the top **Add post** action starts an unscheduled draft. Creation is addressable as `new=1` or
  `new=YYYY-MM-DD`, so reload and back/forward stay deterministic without a second modal.
