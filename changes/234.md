## Fixed

- **Add media URL** no longer accepts a Google Drive share link. The shared media rule refuses it with
  a message that points to **Add a Drive file by link**, which is the path that resolves the file and
  streams real bytes to the provider.
- A delivery whose outcome is **failure** is no longer described as awaiting figures, and refreshing
  figures no longer reports a partial sync that can never complete for that delivery.

## Breaking changes

None.
