## Added

- Thread headers on the Conversations page and Command AI drawer show whether registered agent participants are online, using the existing presence directory.
- Agents can signal ephemeral typing in a thread through the `conversation_set_typing` MCP tool; subscribed operators see a live typing indicator that clears when the signal stops or its TTL expires.
- WebSocket `typing` frames carry the non-authoritative indicator to every operator socket subscribed to that conversation.

## Breaking changes

None.
