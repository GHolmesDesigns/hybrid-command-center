## Fixed

- A project's categories no longer sit flush against what follows them. On a project tile the
  chips ran into the task progress bar and the row of buttons under it, and on a project's own
  page they ran into Open project status, Browse files, Edit and Delete — worst with several
  categories wrapping onto a second line. A project with no categories at all had a different
  gap again in the same place.
- Project Detail now separates the note about what deleting does from the task list below it,
  rather than leaving the two touching.

## Changed

- A project tile and the top of a project's page space their blocks by one consistent distance,
  so the gaps look the same whether a project carries no categories, one, or enough to wrap over
  several lines, and whether its description is a line long or several.

## Breaking changes

None.
