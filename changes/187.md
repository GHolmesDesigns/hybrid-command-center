## Added

- Status board filters now accept multiple clients, projects, priorities, task types, and focus values, with OR matching inside each filter and AND matching between filters.
- Filter selections remain bookmarkable and restore through reload, Back, and Forward navigation.

## Changed

- Status board filters use accessible checkbox popovers with compact selection summaries and a shared **Clear all** action.
- Tag filters keep their existing AND rule: a task must carry every selected tag.

## Fixed

- The production Node server can resolve the shared Signal contrast helper again, allowing the
  required browser suite to start.

## Breaking changes

None.
