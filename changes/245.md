## Fixed

- Scheduling a post is no longer slow. Converting a post's date and time into an instant rebuilt
  the time-zone formatter 1681 times per conversion, which cost about 90 ms each time — and a
  preview converts once per channel while a submit converts again, so taking a publish preview or
  sending a post spent most of a second doing nothing but reading a clock. The formatter is now
  built once per time zone. Previews, submissions, provider comparisons, and the reconciliation
  panel all return in a fraction of the time; the conversion answers exactly as before, including
  refusing a time that daylight saving skips and choosing the earlier of a repeated hour.

## Breaking changes

None.
