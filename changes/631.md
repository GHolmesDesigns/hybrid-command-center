## Added

- **Start Task** in the global top bar and on every Project Status card opens Tasks with that task selected without starting the Pomodoro timer; press **Start** in Tasks to begin.
- The global **Start Task** button resolves the open task detail modal, a `/tasks/:id` page, or the saved timer session, and stays disabled when nothing resolves or the task is unavailable.
- Tasks remembers the selected task in `?task=` so reload and browser Back/Forward restore it.

## Breaking changes

None.
