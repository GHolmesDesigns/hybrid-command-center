## Added

- Command AI assistant server pipeline: encrypted provider keys, daily usage caps, per-thread turn orchestration with tiered write approvals, streaming WebSocket deltas, and Settings API routes.
- Deterministic stub provider for unit and integration tests covering approval flow, permission parity with MCP scopes, and prompt-injection safety.

## Changed

- Operator messages in agent conversations start an assistant turn when the feature is enabled and a provider key is stored.
- Enabling the Command AI assistant forces Live updates on; disabling it leaves Live updates at the operator's last choice.
- `@command-ai` is excluded from mentionable agent labels.

## Breaking changes

None.
