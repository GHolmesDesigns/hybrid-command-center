# Highlight

One colored word or phrase inside a headline, as in “Look *established*, not amateur.”

**You provide:** `children`, `tone` (`cyan`, `yellow`, `magenta`). Place it inside a headline style.

Use one per headline, on the phrase that carries the benefit. On near-black, use `cyan` or `yellow`. On paper-white, use `cyan` at `heading-1` or larger only, and never `yellow`. Never use it in body copy.
