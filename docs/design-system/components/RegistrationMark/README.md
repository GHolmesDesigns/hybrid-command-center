# RegistrationMark

Three overlapping CMYK registration circles: the header mark for playbooks and working deliverables, and a visual through-line inside them.

**You provide:** `size`; `misregistered` for the off-register version that underpins campaign imagery.

The circles multiply where they overlap, so they need nothing behind them to work. This is a motif, not a logo. It never replaces `Logo` on a client-facing identity touchpoint: use `Logo` in proposals, invoices and site headers. Keep the three inks exact and the overlap intact.
