# Button

The one action a view is for.

**You provide:** `children`, `variant` (`primary`, `secondary`, `ghost`), `size` (`md`, `sm`), and `href` to render a link.

Use `primary` at most once per view, and write the label as a direct action in title case: “Start a Project”. Hover inverts to `ink`, so no extra color enters the palette. Use `secondary` for supporting actions and `ghost` for inline ones.

The white label on magenta measures 4.47:1, so keep labels bold and at 15px or larger on `md`.
