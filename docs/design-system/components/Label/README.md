# Label

The DM Mono voice: section labels, spec callouts and running footers, always uppercase with wide letter-spacing.

**You provide:** `children`, `tone` (`muted`, `ink`, `highlight`), `size` (`md`, `sm`), `as`.

Use `highlight` for decorative section numbers only, since cyan on paper-white is below the contrast floor. Anything a reader needs takes `muted` or `ink`.
