# AccentLine

The short cyan, magenta, yellow and black line from the logo, used as a section divider, page break, portfolio category label and web micro-detail.

**You provide:** `size`: `sm` (segmented, running footers and card corners), `md` (section headers), `lg` (feature dividers).

The fourth segment follows `accent-k`, so it flips to paper-white on dark grounds. Use one per block. Never stretch it full width, change the color order or animate it as decoration.
